# RTP-0135 — e2e da T22: medir altura >= 44 px dos botões da faixa de instalar

Reserva: Livre
Origem: QA de RTP-0125 (baixa). O teste unitário só afirma que os botões são filhos de `.acoes` (regra `.acoes > button { min-height: var(--alvo-minimo) }`); jsdom não calcula CSS e `e2e/instalar.spec.ts` não mede altura alguma, então o alvo mínimo de 44 px não tem prova de altura real.

## 1. Plano de execução
No teste Android da faixa em `e2e/instalar.spec.ts` (viewport 390x844), obter `boundingBox()` de `faixa(page).getByRole('button', { name: 'Instalar' })` e de `'Dispensar instalação'` e afirmar `height >= 44` (e `width >= 44` no X).

## 2. Plano de teste
`npx playwright test e2e/instalar.spec.ts` passa; remover o `min-height` de `.acoes > button` faz o teste falhar (mutação temporária, revertida).

## 3. Plano de validação de segurança
Sem impacto (só teste e2e).
