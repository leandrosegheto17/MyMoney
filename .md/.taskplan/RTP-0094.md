# RTP-0094 — Diálogo I-21: texto não fala em "valor total" quando a mudança é de outro campo

Reserva: Livre

## 1. Plano de execução
Origem: QA do TP-0105 (não crítico, baixo). `textoDescarte(parcelas)` sempre diz "Ao mudar o valor total, as N parcelas são recalculadas…", mesmo quando o `confirmar_descarte_ajustes` vem de uma mudança de data da compra, forma ou número de parcelas. Passar ao texto os campos que estavam sendo salvos (`aConfirmar` em `useSalvarLancamento`) e escolher a frase: com `valorTotalCentavos`, a atual; só com data/forma/parcelas, "Ao alterar a compra, …". A frase final para esses casos é decisão de redação do Coordenador (PENDENTE do TP-0105); usar a sugerida até haver resposta.

`textoDescarte.test.ts`: o texto do mockup continua igual para mudança de valor; mudança só de data não cita "valor total".
