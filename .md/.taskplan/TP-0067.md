# TP-0067 — Regra `app.gasto_cartao` (compras) [BD]

Reserva: Livre
ID no TASK.md: TP-0067 · Lote: Lote 13 · Agente: executor · Chapéu: Backend · Est: 3h · Dep: TP-0049, TP-0051 · Status no TASK.md: Pendente
Reqs: CA-03.3; RN-13; ADR-005 §5 · Aceite: Para uma forma de Crédito e um mês: `gasto_mes` = parcelas com data no mês; `comprometido_futuro` = parcelas depois do mês; só o dono enxerga; pgTAP. O caso da fixa paga no crédito fica no TP-0128

## 1. Plano de execução
**Reaproveitamento:** USAR `app.forma_pagamento` (`tipo = 'credito'`, RLS de dono) do TP-0049; `app.parcela` (`data`, `valor_centavos`, índice `(dono_id, data)`) e `app.lancamento_pagamento` (`forma_pagamento_id`, RLS só do pagador) do TP-0051; `app.inicio_mes()` do TP-0004 (normalizar o mês, não usar `date_trunc` solto); privilégios padrão de função (TP-0003); ajudante pgTAP do TP-0013. Esta função é o módulo único da visão do cartão: `api.formas_pagamento` (TP-0068) e `resumo_mes` (TP-0087) vão USÁ-la; o TP-0128 a altera para a fixa no crédito.
**Camada:** banco, `backend/supabase/schemas/app/funcoes/gasto_cartao.sql` (função interna `app.*`, não exposta); pgTAP em `backend/supabase/tests/formas/`.
**Referência visual:** não se aplica.

1. TDD: `tests/formas/gasto_cartao.sql` primeiro, ver falhar.
2. `app.gasto_cartao(p_forma_id uuid, p_mes date) returns table (gasto_mes_centavos bigint, comprometido_futuro_centavos bigint)`, `language sql stable security invoker set search_path = ''`. Nomes das colunas = campos de `respostas/formas-pagamento.json`.
3. Estrutura pensada para o TP-0128: um CTE `itens(data_cartao, valor_centavos)` com as **compras** (`parcela.data` como data de cartão, ADR-005 §5: `parcela p join lancamento_pagamento lp on lp.lancamento_id = p.lancamento_id where lp.forma_pagamento_id = p_forma_id`), e a agregação por cima:
   - `v_mes := app.inicio_mes(p_mes)`; `gasto_mes` = `Σ valor` com `data_cartao >= v_mes and data_cartao < v_mes + interval '1 month'`; `comprometido_futuro` = `Σ valor` com `data_cartao >= v_mes + 1 mês`; `coalesce(…, 0)`.
   - O TP-0128 só acrescenta um `union all` no CTE; registrar a intenção num comentário curto de propósito (sem ID de tarefa).
4. "Só o dono enxerga": a forma precisa ser visível e de Crédito (`exists (select 1 from app.forma_pagamento f where f.id = p_forma_id and f.tipo = 'credito')`); senão devolve 1 linha com os dois campos `null` (igual para forma de B, inexistente ou Pix/Débito: não revela existência). A RLS de `lancamento_pagamento` já impede B de somar parcelas de A, mesmo de compra conjunta que B vê em `parcela`.
5. `supabase db diff -f gasto_cartao`; `pnpm local:resetar`; `pnpm contrato:gerar` sem diff.

Não fazer: ler `valor_total_centavos` (G-11); fatura, vencimento de fatura ou pagamento de cartão (fora de escopo, RN-13); a fixa paga no crédito (TP-0128); `security definer`; ID de tarefa no SQL.
