# RTP-0092 — LinkMais com ícone dir como no mockup

Reserva: Livre
Status-local: Concluída · aguarda QA

## 1. Plano de execução
Origem: QA do TP-0090 (não crítico, baixo). O `a.link-mais` do mockup ("Ver orçamento", "Nova meta") traz o ícone `dir` depois do texto; `LinkMais` não o renderiza (registrado pelo executor do TP-0090). Acrescentar o ícone (`aria-hidden`).

## 2. Plano de teste
`LinkMais.test.tsx`: o ícone existe, é decorativo e o nome acessível do link continua só o texto.

## 3. Plano de validação de segurança
Não toca superfície de segurança.

## 4. Resultado da execução
`LinkMais` ganhou a prop opcional `seta`, que renderiza `<Icone nome="dir" />` (aria-hidden) após o texto. Prop opcional porque no mockup os links de Entrar/Nova senha ("Esqueci minha senha", "Voltar para Entrar") não têm o ícone. `ResumoOrcamento` ("Ver orçamento") e `CartaoMetas` ("Nova meta") passam `seta`.
Arquivos: base/LinkMais.tsx, base/LinkMais.test.tsx, ResumoOrcamento.tsx, CartaoMetas.tsx (os dois últimos fora da lista do plano, edição de 1 linha cada, necessária para usar a prop).
Testes: `npx vitest run LinkMais.test.tsx ResumoOrcamento CartaoMetas` — 13 passando, 0 falhando.
Checklist de convenções: sem código copiado, sem ID de tarefa em comentário, comentário do componente atualizado, arquivos < 300 linhas, sem import que fure fronteira. Tela: sem comparação visual (alteração de componente, não de tela).
