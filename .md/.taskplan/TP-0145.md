1. TDD: pgTAP primeiro, com os números do mockup (seção 2).
2. `app.progresso_meta(p_meta_id uuid, p_hoje date default app.hoje()) returns table (guardado_centavos bigint, falta_centavos bigint, percentual integer, mensal_necessario_centavos bigint, atingida boolean, por_local jsonb)`; `language sql stable security invoker set search_path = ''`. Meta invisível ou inexistente → zero linhas (a RLS decide; quem chama trata). `p_hoje` só para o teste (mesmo recurso do `app.hoje(p_instante)`, TP-0004).
3. Regras (SDD §5):
   - `guardado = Σ valor (aporte) − Σ valor (retirada)` dos movimentos da meta (coalesce 0).
   - `falta = greatest(0, alvo − guardado)`.
   - `percentual = least(100, round(100.0 * guardado / alvo))::int`, mas 99 quando `guardado < alvo` e o arredondamento der 100 (evita "100%" sem "Atingida"); interpretação, registrar em `## 4`. Confere: 1.850.000/3.000.000 → 62; 620.000/1.200.000 → 52.
   - `atingida = guardado >= alvo` (derivação, CA-17.3). `atingida_em` só guarda a data e é mantido pelo TP-0150; não ler aqui.
   - `mensal_necessario`: `null` sem prazo; `meses = (ano/mês do prazo) − (ano/mês de app.inicio_mes(p_hoje))` em meses inteiros; `ceil(falta / meses)` em inteiros ("com teto" = arredondar para cima; confere com o mockup: 580.000 ÷ 9 = 64.445 para `2027-07`; 2.000.000 ÷ 26 = 76.924 para `2028-12`, hoje 2026-10-09).
     PENDENTE: com prazo no mês corrente ou já passado (`meses <= 0`) e com `falta = 0`, qual o mensal? Proposta: `meses = greatest(1, meses)` (prazo vencido pede a falta inteira no mês) e `falta = 0` → `null` (nada a guardar; a T10 mostra "Atingida").
   - `por_local`: `[{local, guardado_centavos}]` com o saldo por `local` (texto exato, já sem espaços nas pontas pelo `check` do TP-0144), só os com saldo > 0, ordem `guardado desc, local`; sem movimentos → `[]` (`meta-carro.json`). Confere com `meta-detalhe.json`: Nubank 420.000, Inter 200.000.
4. Inteiros em todo o cálculo (`bigint`, divisão inteira com teto por `(falta + meses − 1) / meses`); sem `numeric` gravado (G-10). Sem leitura de `lancamento`/`parcela`.
5. `supabase db diff -f progresso_meta`; `pnpm local:resetar`.

Não fazer: expor no schema `api` (TP-0146); gravar `atingida_em`; agrupar local sem diferenciar maiúsculas (a retirada escolhe da lista, T13; interpretação registrada).
