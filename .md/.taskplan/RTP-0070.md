# RTP-0070 — checar-aditiva.sh: falha aberta quando perl falta

ID no TASK.md: RTP-0070 · Lote: Refatoração Lote-21 · Agente: executor · Chapéu: Backend (operação) · Est: 0.5h · Dep: RTP-0060 · Status no TASK.md: Pendente
Reqs: QA de RTP-0060 (achado médio); G-12; falhar fechado · Aceite: sem perl no PATH o script sai com código diferente de 0 e não aprova migration; caso novo no teste; 44 casos atuais verdes

## 1. Plano de execução
Em `achados_nao_aditivos`, `sql="$(sql_sem_comentarios ...)"` roda dentro de um pipeline em `$(...)` e o erro de `perl: command not found` não propaga: o script imprime "ok: ... é aditiva" e sai 0 (reproduzido com PATH sem perl). Verificar `command -v perl` no início de `main` (exit 2) e/ou propagar o status da varredura. Em ubuntu-latest o perl existe, então o risco é de execução local/outro runner.

## 2. Plano de teste
Caso novo: PATH sem perl com migration com `drop` e com migration aditiva, ambas saem com código diferente de 0; 44 casos atuais verdes.

## 3. Plano de validação de segurança
Garante falha fechada da checagem G-12 quando a dependência da varredura falta.
