## 1. Plano de execução
**Reaproveitamento:** USAR o ref de produção registrado em `backend/operacao/setup/limpeza.md` (TP-0009; não inventar nem ler de variável); o pacote `frontend/web` e o build do TP-0021. Nada a extrair.
**Camada:** configuração de hospedagem do `@mymoney/web`: `frontend/web/vercel.json` (o root do projeto Vercel é `frontend/web`, TP-0029); verificador em `frontend/web/scripts/` (ferramenta de teste, fora de `src/`).
**Referência visual:** não se aplica.

1. `frontend/web/vercel.json`: `rewrites: [{ source: '/(.*)', destination: '/index.html' }]` (a Vercel serve arquivo existente antes do rewrite, então `assets/`, `sw.js` e `manifest.webmanifest` continuam diretos).
2. `headers` em `source: '/(.*)'`:
   - `Content-Security-Policy`: `default-src 'self'; connect-src 'self' https://<ref>.supabase.co; script-src 'self'; style-src 'self'; img-src 'self'; font-src 'self'; manifest-src 'self'; worker-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'`. Sem `wss://` (não há Realtime, SDD §6). Se o build tiver `data:` (assets inline do Vite), preferir `build.assetsInlineLimit: 0` a afrouxar `img-src`/`font-src`.
   - `Strict-Transport-Security: max-age=63072000; includeSubDomains`; `X-Content-Type-Options: nosniff`; `Referrer-Policy: no-referrer`; `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=(), bluetooth=(), interest-cohort=()`.
3. `scripts/verificarHosts.mjs`: `hostsEncontrados(pasta)` lista os hosts de literais `https?://` em `dist/**/*.{js,css,html,webmanifest}`; CLI sai 1 se houver host fora de `<ref>.supabase.co`. Script `"verificar-hosts"` no `package.json` (o TP-0030 o põe no CI).
   AGUARDA GESTOR (mudança na checagem da G-20): o Coordenador propôs ao Gestor acrescentar à coluna "Como verificar" da G-20: "...exceto os literais de uma lista fechada escrita no próprio teste, de URLs que o código nunca busca (namespace `http://www.w3.org/2000/svg`, `https://react.dev/errors/` e links de documentação de bibliotecas), cada uma com comentário do motivo; acrescentar item à lista segue a governança de exceções". Enquanto o Gestor não aprovar: escrever `verificarHosts` com a lista vazia e registrar em `## 4` os hosts que o build real acusa (a evidência vai para o Gestor); a CSP não muda em nenhum caso.
4. `frontend/README.md`: os cabeçalhos, onde mudar o ref se o projeto Supabase for recriado e que acrescentar host à CSP é exceção da G-20.
5. Coordenação: o `vite.config.ts` é editado pelo TP-0027 na mesma rodada; se precisar do `assetsInlineLimit`, reler antes de editar.

Não fazer: configuração do projeto na Vercel (TP-0029); `unsafe-inline`/`unsafe-eval` "para funcionar"; curinga `*.supabase.co`.
