**Camada:** `backend/operacao/setup/` (SDD §2 árvore alvo): `conferencia-painel.md`.
**Referência visual:** não se aplica.
Regra [U] (TASK §1.2): o Executor mostra item por item o que mudar no painel; o usuário aplica (ou confirma na hora a aplicação); nada é alterado sem ele.
Passos:
1. Montar a tabela de conferência a partir do `config.toml`: `auth.enable_signup=false`, `auth.minimum_password_length=12`, `api.schemas=["api"]`, GraphQL desligado (extensão `pg_graphql` removida/desabilitada no painel), `auth.jwt_expiry=3600`, `auth.enable_refresh_token_rotation=true`, `auth.site_url` e `auth.additional_redirect_urls`.
2. Com o usuário, no painel do projeto (ref de `limpeza.md`): Auth > Sign In/Providers (signup off, senha 12), Auth > Sessions/JWT (3600 s, rotação), Auth > URL Configuration (Site URL e Redirect), API Settings > Exposed schemas = só `api` (tirar `public` e `graphql_public`), Database > Extensions (`pg_graphql` off).
3. Gravar `conferencia-painel.md`: item | valor no painel | valor no `config.toml` | igual? | data. Se o `config.toml` local tiver valor diferente do exigido (ex.: `site_url` local é `http://127.0.0.1`), registrar a coluna "local" separada e explicar; a divergência só é aceitável nas URLs (local × produção).
4. Conferência objetiva, além do olho: `curl` com a `anon` em `/auth/v1/settings` (`disable_signup: true`) e `POST /auth/v1/signup` recusado; `POST /graphql/v1` não responde dados.
NÃO: criar usuários (é tarefa posterior), aplicar migration (TP-0011), gravar chave em arquivo versionado.

## 2. Plano de teste
Tarefa de configuração sem código; a evidência é verificável por comando:
- `curl -s <url>/auth/v1/settings -H "apikey: <anon>"` → `disable_signup: true`;
- `curl -s -X POST <url>/auth/v1/signup ... ` com e-mail fictício → erro "Signups not allowed";
- `curl -s -X POST <url>/graphql/v1 ...` → sem dados (extensão desligada);
- `curl -s <url>/rest/v1/ -H "Accept-Profile: public"` → schema não exposto.
Itens sem endpoint (senha 12, JWT 3600 s, rotação, redirect) conferidos visualmente e registrados na tabela.
Toda saída de comando (sem chave) vai para `## 4`. Não roda teste automatizado novo; o teste do `config.toml` (G-02, G-16) é do TP-0002.
