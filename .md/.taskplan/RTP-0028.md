# RTP-0028 — Casos testes-api de arquivar/excluir forma: usar os ids do seed

Reserva: Livre
ID no TASK.md: RTP-0028 · Lote: Refatoração Lote-11 · Agente: executor · Chapéu: Backend · Est: 0.5h · Dep: TP-0057 · Status no TASK.md: Pendente
Reqs: CA-03.5; G-05; achado de QA de TP-0057 · Aceite: `arquivar-forma.test.ts` e `excluir-forma.test.ts` usam o id real do seed (forma `00000000-0000-4000-8000-000000000303` de A, usada pela "Geladeira nova"); A excluindo essa forma recebe `em_uso`; B arquivando/excluindo recebe `registro_invalido` contra dado que existe

## 1. Plano de execução
Origem: achado não crítico do QA de TP-0057. Os dois casos declaram `FORMA_DE_A`/`FORMA_EM_USO = 'e1000000-0000-4000-8000-000000000303'`, id que só existe nos pgTAP; os seeds `03-formas`/`05-lancamentos` usam o prefixo `00000000-0000-4000-8000-…`. Efeito (reproduzido em banco descartável com os seeds): `excluir_forma` do id do seed devolve `em_uso`, do id `e1000000-…` devolve `registro_invalido`; logo o caso "A não exclui forma com lançamento ligado (em_uso)" falha no ambiente real e os dois casos de B passam sem exercitar a forma de A (G-05 vazio). Trocar as constantes pelo id do seed. Mesmo prefixo errado em `salvar-forma.test.ts` (RTP-0022), `alterar-data-parcela`, `dados-lancamento`, `excluir-lancamento` e `lancar-despesa`: conferir antes de corrigir, para não conflitar com RTP-0022.

## 2. Plano de teste
`pnpm local:resetar`; `pnpm --filter @mymoney/testes-api test -- forma` verde; o caso `em_uso` deve falhar se a função for trocada por um stub que apaga a forma.

## 3. Plano de validação de segurança
G-05: as asserções de B passam a exercitar a forma existente de A (forma de outro membro igual a forma inexistente, nunca `em_uso`).

## 4. Resultado da execução
Feito: constantes `FORMA_DE_A` e `FORMA_EM_USO` trocadas de `e1000000-0000-4000-8000-000000000303` para o id do seed `00000000-0000-4000-8000-000000000303`. Prefixo errado conferido: só esses dois casos de forma o usavam em `backend/testes-api`; `salvar-forma.test.ts` (RTP-0022) e os demais citados no plano não continham `e1000000-…000303` (não tocados). Os `e1000000-…` restantes em ajustar-saldo/excluir-conta/arquivar-conta/arquivar-categoria são de conta/categoria, fora do escopo.
Arquivos alterados:

- backend/testes-api/casos/excluir-forma.test.ts
