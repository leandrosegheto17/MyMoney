# RTP-0122 — Passo "Instale o app" dos Primeiros passos: destino definitivo (T22)

Reserva: Livre
Origem: QA de TP-0095 (baixa). O link "Instale o app no celular" aponta para `/ajustes?instalar=1`, destino provisório (a T22 é folha sem rota); o aceite pede "instalar → T22".

## 1. Plano de execução
Quando a T22 tiver rota/ação, apontar o passo 3 de `PrimeirosPassos` para ela (mesma decisão do atalho de instalar do TP-0089) e remover o destino provisório.

## 2. Plano de teste
`npx vitest run src/componentes/inicio/PrimeirosPassos`: o link do passo 3 leva ao destino da T22.

## 3. Plano de validação de segurança
Sem impacto (só navegação interna).
