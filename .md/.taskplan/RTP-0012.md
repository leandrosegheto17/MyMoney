# RTP-0012 — Lint de fronteira: não sinalizar X.from() que não seja cliente supabase

Reserva: Livre
ID no TASK.md: RTP-0012 · Lote: Refatoração Lote-4 · Agente: executor · Chapéu: Frontend · Est: 1h · Dep: RTP-0008 · Status no TASK.md: Pendente
Reqs: QA de RTP-0008; G-07/G-08 · Aceite: fixture com `const b = Uint8Array.from([1])` (e `Buffer.from`/`Observable.from`) em `componentes/` passa sem erro no lint; fixtures de RTP-0008 (`const q = s.from(x); q.insert(y)`, import dinâmico) seguem falhando; `pnpm test test/lint` e `pnpm lint` verdes

## 1. Plano de execução
Origem: achado não crítico do QA de RTP-0008. O selector de `.from(...)` guardado em variável/atribuição só exclui `Array`; `const b = Uint8Array.from(x)`, `Buffer.from`, `Observable.from` etc. fora de `dados/` dão falso positivo em `no-restricted-syntax`. Refinar em `eslint.fronteiras.js` (ex.: exigir 1 argumento string literal/identificador de tabela e objeto que não seja construtor com inicial maiúscula, ou lista de exclusão maior), mantendo a detecção do construtor cru do supabase.

## 2. Plano de teste
Fixtures novas em `frontend/web/test/lint/arvore/src/` (permitido: `Uint8Array.from`, `Buffer.from`) e casos em `fronteirasDinamicas.test.ts`; `pnpm test test/lint` e `pnpm lint` verdes.

## 3. Plano de validação de segurança
Não toca superfície de segurança; só config de lint e fixtures.

## 4. Resultado da execução
- Feito: selector de `.from()` guardado em variável/atribuição em `eslint.fronteiras.js` agora exclui qualquer objeto com inicial maiúscula (`:not([callee.object.name=/^[A-Z]/])`), cobrindo Array/Uint8Array/Buffer/Observable; cliente supabase (minúsculo) segue detectado. Fixtures em `componentes/` + casos "permitido" em `fronteirasDinamicas.test.ts`.
- Arquivos: frontend/web/eslint.fronteiras.js; frontend/web/test/lint/fronteirasDinamicas.test.ts; frontend/web/test/lint/arvore/src/componentes/permitidoUint8ArrayFrom.ts, permitidoBufferFrom.ts, permitidoObservableFrom.ts.
- Testes: `npx vitest run test/lint` (em frontend/web): 3 arquivos, 30 testes verdes. `npx eslint frontend/web`: único erro é de outra tarefa em curso (src/componentes/EstadosDeLeitura.tsx importa ganchos/), fora do escopo desta; nenhum erro nos arquivos desta tarefa.
- Riscos: `X.from()` com construtor maiúsculo que seja cliente supabase não é detectado (convenção: cliente é minúsculo).
