## 4. Resultado da execução
**Feito:** `ListaParcelas` deixou de salvar a cada `onChange`. Regra: o `change` confirma na hora só se a parcela abriu o seletor nativo (`showPicker`) ou o campo não tem foco; com o campo visível e focado (digitação), só `blur` ou `Enter` confirmam. `Escape` restaura `p.data` e fecha. Vazio ou igual ao atual não chama; um guard por parcela (`emSalvamento`) evita segunda chamada pelo blur logo após o `change` do seletor. Contêiner fechado ganhou `aria-hidden` (o CSS `seletorOculto` não usa display:none). `CampoData` e CSS intactos.
**Testes:** `pnpm exec vitest run src/componentes/lancamento/ListaParcelas.test.tsx src/paginas/Lancamento.test.tsx` → 29 passando, 0 falhando; `tsc --noEmit` sem erros.
