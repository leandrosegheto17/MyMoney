## 1. Plano de execução
**Reaproveitamento:** USAR o pacote `frontend/web` do TP-0021 (Vitest). Nada a extrair: é o módulo que as tarefas seguintes usam (`CampoValor` TP-0035, `SeletorMes` TP-0041, `LinhaLancamento` TP-0101, títulos de página). Quem precisar de outra variação de formato acrescenta **aqui**, não no componente.
**Camada:** `frontend/web/src/formatacao/` (SDD §2: não importa nenhuma outra camada; nem React, nem React Router).
**Referência visual:** não se aplica (os textos esperados vêm do mockup: "R$ 2.418,70", "05/07/2026", "Outubro de 2026", aria-label "Mês anterior: setembro de 2026").

1. `formatacao/moeda.ts`: `formatarMoeda(centavos: number): string` → "R$ 1.234,56", "R$ 0,00". Usar `Intl.NumberFormat('pt-BR', { style: 'currency', currency: 'BRL' })` e trocar o NBSP (U+00A0) que o Intl gera pelo espaço comum que o mockup usa ("R$ 2.418,70", conferido no HTML), para o texto visível e o acessível serem a mesma string (UX-SPEC §5, 3.1.1). Rejeitar (lançar) valor não inteiro: centavo é inteiro (ADR-004).
   Sinal: negativo sempre "− R$ 300,00" (U+2212 + espaço); `formatarMoeda(centavos, { sinal: true })` acrescenta "+ R$ 1.000,00" no positivo (zero sem sinal). Texto acessível igual ao visível.
   RESOLVIDO (Coordenador, 2026-10-09): o sinal entra nesta tarefa, num formato só: sinal + espaço + "R$ …", que é o que as páginas do mockup usam (`conta--sucesso`, `inicio--sucesso`, `meta--sucesso`; o "+R$ 12,30" sem espaço só existia no texto do TASK/UX-SPEC e foi corrigido para "− R$ 12,30"/"+ R$ 12,30"). Registrado no aceite do TP-0024 e na UX-SPEC §4 (Textos complementares, X-01).
2. `formatacao/centavos.ts`: `digitosParaCentavos(texto: string): number`: só os dígitos contam ("4590" → 4590, "" → 0, "0045" → 45, "R$ 45,90" colado → 4590). Sem limite de valor aqui (o limite de entrada é do `CampoValor`, TP-0035); garantir `Number.isSafeInteger` no resultado.
3. `formatacao/data.ts`: `formatarData('2026-07-05')` → "05/07/2026" (por fatiamento da string, sem `new Date('YYYY-MM-DD')`, que vira UTC e pode cair no dia anterior); `hojeEmSaoPaulo(agora = new Date()): string` `YYYY-MM-DD` via `Intl.DateTimeFormat('en-CA', { timeZone: 'America/Sao_Paulo' })` com `formatToParts`. Serve de padrão de data do lançamento; o servidor revalida (SDD §2).
   `formatarDataCurta('2026-10-10')` → "10/10" e `formatarMesCurto('2027-07')` → "jul/2027" (também aceita `YYYY-MM-01`).
   RESOLVIDO (Coordenador, 2026-10-09): entram agora (lógica usada por várias telas nasce uma vez: T03, T04, T05, T10, T23). Registrado no aceite do TP-0024 (TASK.md).
4. `formatacao/mes.ts`: `formatarMes('2026-10')` → "Outubro de 2026" e `formatarMes('2026-09', { minuscula: true })` → "setembro de 2026" (aria-label do `SeletorMes`, UX-SPEC §5). Aceitar também `YYYY-MM-01` (`mes_corrente` do `contexto.json`). `lerMesDaUrl(params: URLSearchParams): string | null`: só `^\d{4}-(0[1-9]|1[0-2])$`, senão `null` (quem chama decide o padrão, o mês corrente do RF-14). `escreverMesNaUrl(params, mes): URLSearchParams`: devolve cópia com `mes` trocado, preservando os demais parâmetros (`escopo`, `categoria`…).
5. Mês anterior/seguinte não está no aceite: o TP-0041 acrescenta em `mes.ts` se precisar.
6. Um arquivo por assunto, cada um bem abaixo de 300 linhas; sem barril.

Não fazer: nenhum cálculo de regra (parcela, competência, total); nenhuma leitura de `window.location` aqui (a página passa os parâmetros).

## 2. Plano de teste
Vitest, um arquivo de teste por módulo em `src/formatacao/*.test.ts`:
- Moeda: 0 → "R$ 0,00"; 1 → "R$ 0,01"; 123456 → "R$ 1.234,56"; 99999999999 → "R$ 999.999.999,99"; resultado sem U+00A0; não inteiro lança; −30000 → "− R$ 300,00"; `{ sinal: true }` com 100000 → "+ R$ 1.000,00" e 0 → "R$ 0,00". Data curta "2026-10-10" → "10/10"; mês curto "2027-07" e "2027-07-01" → "jul/2027".
- Dígitos: "4590" → 4590; "" → 0; "0" → 0; "0045" → 45; "R$ 45,90" → 4590; 15 dígitos → seguro.
- Data: "2026-07-05" → "05/07/2026"; "2026-12-31"; `hojeEmSaoPaulo(new Date('2026-10-10T02:30:00Z'))` → "2026-10-09" (23h30 em SP); `new Date('2027-01-01T02:30:00Z')` → "2026-12-31" (virada de ano); `new Date('2026-10-10T03:00:00Z')` → "2026-10-10". Rodar também com `TZ=UTC` e `TZ=Asia/Tokyo` (o resultado não pode depender do fuso da máquina).
- Mês: "2026-10" → "Outubro de 2026"; "2026-01"/"2026-12"; minúscula; "2026-10-01" aceito; `lerMesDaUrl`: "2026-10" ok; "2026-13", "2026-1", "abc", ausente → `null`; `escreverMesNaUrl` preserva `escopo=casa` e não muta a entrada.
- Cobertura do módulo: 100% de linhas (módulo pequeno e puro).
- Comando: `pnpm --filter @mymoney/web test -- src/formatacao`.
