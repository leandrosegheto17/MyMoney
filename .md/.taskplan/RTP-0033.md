## 1. Plano de execução

Efeito com a API local: o caso "A simula e ajusta" recebe `registro_invalido` e falha, e o caso de B passa por acaso (id inexistente), sem provar o isolamento. Trocar `CONTA_A` pelo id do seed (manter o id inexistente, trocando também o prefixo para `00000000-…02ff`). Sem mudar a função. Os outros arquivos com `e1000000-…` (arquivar-conta, excluir-conta, arquivar-categoria) são de outras tarefas: conferir se já têm RTP antes de tocar.
