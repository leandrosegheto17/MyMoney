# RTP-0069 — checar-aditiva.sh: tag de dollar-quote com não-ASCII não é reconhecida

ID no TASK.md: RTP-0069 · Lote: Refatoração Lote-21 · Agente: executor · Chapéu: Backend (operação) · Est: 0.5h · Dep: RTP-0060 · Status no TASK.md: Pendente
Reqs: QA de RTP-0060 (achado alto); G-12; ADR-011 §4.2 · Aceite: `select $é$ -- $é$; drop table app.t;` é reprovada sem justificativa; caso novo no teste; 44 casos atuais verdes

## 1. Plano de execução
O regex de abertura de dollar-quote em `sql_sem_comentarios` só aceita `[A-Za-z_][A-Za-z0-9_]*`. No Postgres a tag aceita letras com diacrítico e bytes \200-\377. Com `$é$ -- $é$; drop table app.t;` o `$` cai no ramo genérico, o `--` vira comentário e o drop some (reproduzido: rc 0, "é aditiva"). Ampliar a tag para incluir bytes não-ASCII (perl em bytes: `[^\x00-\x7F]`), nos dois pontos (início da tag e continuação).

## 2. Plano de teste
Casos novos em `checar-aditiva.test.sh`: `$é$ -- $é$; drop ...` falha; `$é$ ... $é$` sem drop passa; 44 casos atuais verdes.

## 3. Plano de validação de segurança
Fecha bypass da regra G-12 por tag de dollar-quote não-ASCII; sem mudança de superfície.
