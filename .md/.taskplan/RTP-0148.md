# RTP-0148 — E2E @integracao da receita deixa lançamentos no banco local

Reserva: Livre
Status-local: Concluída · QA ✔
Origem: QA de TP-0116 (não crítico 1). `e2e/integracao/lancar-receita.spec.ts` lança R$ 100,00 no Supabase local e não remove o lançamento; cada rodada soma mais uma receita (3 rodadas = 3 receitas de teste). O teste é relativo (antes/depois), então passa sempre, mas o saldo e as "Receitas" do seed derivam e podem atrapalhar outros e2e/comparações.

## 1. Plano de execução
Remover a receita criada ao fim do teste (limpeza via API local de teste, só em localhost) ou usar conta/usuário isolado. Sem mudar o código da aplicação.

## 2. Plano de teste
Rodar `pnpm exec playwright test --grep @integracao e2e/integracao/lancar-receita.spec.ts` duas vezes seguidas: passa nas duas e o saldo da conta e as receitas do mês ficam iguais antes e depois.

## 3. Plano de validação de segurança
G-06: limpeza só contra localhost; nenhuma chave de serviço no repositório.

## 4. Resultado da execução
Novo `e2e/apoio/limpeza-local.ts`: registra os `p_id` enviados a `lancar_receita`/`lancar_despesa` pela página e, no `afterEach`, entra com o usuário de teste (senha do seed) e chama `excluir_lancamento` no Supabase local. Recusa host que não seja 127.0.0.1/localhost; usa só a chave anon de `.env.local` (nenhuma chave de serviço). Spec ajustado para registrar e excluir. Código da aplicação intocado.

Testes: `PORTA=5391 pnpm exec playwright test --grep @integracao e2e/integracao/lancar-receita.spec.ts` rodado 3 vezes, 3 passando. Contagem de lançamentos "Salário" do mês via API estável (10) entre as rodadas, ou seja, a rodada não deixa receita nova. As 10 existentes são resíduo de rodadas anteriores à limpeza (não removidas aqui). Observação: a porta 5293 estava ocupada por outro Vite em modo de comparação (URL falsa); usar porta própria.

Checklist: sem cópia >10 linhas; sem IDs de tarefa em código; sem comentário falso; arquivos pequenos; sem import que fure fronteiras.

**Arquivos alterados:**
- frontend/web/e2e/apoio/limpeza-local.ts
- frontend/web/e2e/integracao/lancar-receita.spec.ts
