# RTP-0166 — cadastro-membros.md: exigir conferência do ref no painel quando o SQL for rodado pelo SQL Editor (origem TP-0112)

Reserva: Livre
Grupo: Refatoração Lote-22
Origem: DevSecOps da TP-0112 (achado Baixo). No passo 5 de `backend/operacao/setup/cadastro-membros.md`, a alternativa do SQL Editor do painel não diz qual conferência substitui a confirmação digitada do ref (G-14); na execução real o registro ficou "ref digitado: não aplicável".

## 1. Plano de execução
Editar `backend/operacao/setup/cadastro-membros.md`: no passo 5, na alternativa do SQL Editor, exigir conferir o ref do projeto na URL do painel antes de rodar; na tabela "Registro", acrescentar a linha "Ref conferido no painel". Sem dado real. **Reaproveitamento:** editar o arquivo existente. **NÃO:** mexer no `.sql`, nem criar arquivo novo.

## 2. Plano de teste
Leitura do roteiro: passo 5 e tabela coerentes; `gitleaks` no arquivo sem achados.

## 3. Plano de validação de segurança
G-14: a alternativa do painel tem uma conferência explícita do ref; G-15: nenhum e-mail, senha, `user_id` nem nome real no arquivo.
